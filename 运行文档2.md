健康咨询管理系统 - 运行文档
一、项目概述
本项目是一个基于 Node.js + MySQL 的健康咨询管理系统，提供用户健康数据管理和病情咨询功能。

二、技术栈
分类	技术	版本要求
前端	HTML5 / CSS3 / JavaScript	-
后端	Node.js + Express	>= 18.x
数据库	MySQL	>= 5.7
三、环境要求
Node.js >= 18.0.0
MySQL >= 5.7
npm >= 9.0.0
四、安装与配置
4.1 安装依赖

Bash

cd c:\ai\yishen-AI
npm install
4.2 数据库配置
创建 .env 文件：


env

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your-password
DB_NAME=yishen_ai
DB_PORT=3306
PORT=3000
JWT_SECRET=your-secret-key
4.3 创建数据库表

SQL

CREATE DATABASE yishen_ai CHARACTER SET utf8mb4;

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    email VARCHAR(100),
    name VARCHAR(50),
    gender ENUM('男', '女'),
    age INT,
    role ENUM('user', 'admin') DEFAULT 'user',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE health_data (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    temperature DECIMAL(4,1),
    blood_pressure VARCHAR(20),
    heart_rate INT,
    blood_sugar DECIMAL(5,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE consultations (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    symptoms TEXT NOT NULL,
    duration VARCHAR(50),
    other_symptoms TEXT,
    department_suggestion VARCHAR(100),
    treatment_suggestion TEXT,
    medication_suggestion TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE symptom_keywords (
    id INT AUTO_INCREMENT PRIMARY KEY,
    keyword VARCHAR(50) NOT NULL,
    disease VARCHAR(100) NOT NULL,
    department VARCHAR(50),
    treatment TEXT,
    medication TEXT
);
五、启动运行

Bash

# 开发环境
npm start

# 或使用 pm2 生产环境
npm install -g pm2
pm2 start server.js --name yishen-ai

八、常见问题
数据库连接失败：检查 MySQL 服务和配置信息
症状匹配失败：检查 symptom_keywords 表数据
样式错乱：检查 style.css 路径和缓存
